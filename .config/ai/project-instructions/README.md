# Project Instruction Templates

These files distribute curated project-specific instructions without loading them as shared
guidelines. Template files use the `.template` suffix deliberately.

The `masterchief` set mirrors existing project instruction files between the isolated Raynor and
Zeratul universes. Install a template only when the matching repository and destination instruction
file already exist. Do not create instruction files for projects that do not already have them.

Never inspect one MasterChief universe from the other; installation must run from inside the
destination universe.
