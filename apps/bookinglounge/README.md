# BookingLounge local commands

`test-bl` runs the BookingLounge test gate. `bl-clean` previews its disposable
output and removes it after you type `clean`. `bl-clean --dry-run` lists the
targets and their sizes without deleting anything. Both commands use
`~/projects/bookinglounge` by default and accept a `BL_REPO` override.

The cleanup allowlist is in `clean.sh`. It covers `release-gate/temporary`,
legacy gate reports, backend `bin`/`obj` and test results, and the portal's
build/cache/browser results. These locations are regenerated by later builds or
test runs. It preserves `release-gate/retained`, `Build` (including signed app
archives and exports), local backups, dependencies, source files, and simulator
devices. The command refuses symlinked targets, tracked files, and directories
with open files. Run it when the test gate and builds have finished.

These aliases are local to Hades; the vps1 alias set has no BookingLounge test
checkout to clean. Reload the shell configuration or open a new terminal after
installing an alias update.
